## Project Overview
We analyzed whether crime rates affect housing prices across NYC boroughs
using real arrest data and property sale records.

## Datasets
- [NYPD Arrests and Crime Dataset](https://www.kaggle.com/datasets/kamaravichow/nypd-arrests-and-crime-dataset)
- [NYC Housing Prices Dataset](https://www.kaggle.com/datasets/ishank2005/nyc-housing-prices-csv)

## Key Findings
- Brooklyn has the most crimes but also the highest median sale price ($1,065,000)
- Crime count alone only explains 6% of housing price variation (R² = 0.06)
- T-Test showed a statistically significant difference (p < 0.0001) but in the
  opposite direction than expected — higher crime areas are more expensive
